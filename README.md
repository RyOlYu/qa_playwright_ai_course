# установка
 - Node.js
 - `npm i` из корня

# структура и запуск (на commit - )
- задачи помогала делать нейронка, весь диалог здесь - [ai](./ai-creating-course-dialog.md)
- проект имитирует магазин, код написан на чистом js/html в специально не оптимальном стиле,
- файлы сервера: server - [server](./server/server.mjs), [функции работы с данными](./server/db.mjs),
[функции аутентификации](./server/auth.mjs)
- файлы ui части: html - [ui](./ui/index.html), логика - [js](./ui/app.js)
- сервер отдает ui, ui логика имитирует SPA
- запуск только одного файла с тестами - [npm run start:one](./package.json#9)
- запуск всех файлов с тестами в ui режиме(dev режим для playwright) - [npm run start:ui](./package.json#10)
- запуск всех файлов с тестами без показа браузера(ci режим playwright) - [npm run start:ci](./package.json#11)
- запуск сервера отдельно - [npm run start:server](./package.json#12)
- для создания своих скриптов запуска ts/js файлов - используем `tsx`

# работа с проектом
- задачи здесь [tasks](./tasks/) 
- берем задачу и делаем отдельную папку здесь [tests](./tests/) и пишем два файла - `*.feature` `*.spec.ts`,
пример [example](./tests/examples/5/)
- читаем задачу, записываем .feature. В начале читаем и код для теста сразу - он будет внизу, но как только начинает получатся - в начале нужно пытаться продумывать решение самостоятельно. Решение теста в виде кода сразу писать не надо - перед этим идем по полезным ссылкам и читаем, записываем в конспект новое. Потом пытаемся воспроизвести решение в `*.spec.ts`, все сложности, мысли о коде и тп. записываем сразу в файле в виде доки `/** */`
